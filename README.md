# Stats Soccer U13F-D1 Levis Est

Application HTML autonome pour suivre les statistiques d'une equipe de soccer.

## Fonctionnalites
- Enregistrer les matchs (adversaire, pointage, date)
- Historique des matchs
- Buteuses, passeuses, joueuses match complet, etoiles du match
- Statistiques d'equipe et statistiques des joueuses
- Export CSV de l'historique

## Pages
- `index.html` : saisie des matchs + stats d'equipe + historique
- `player-stats.html` : gestion des joueuses + stats individuelles
- `stats-history.html` : stats d'equipe + historique

## Utilisation
1. Ouvrir `index.html` dans un navigateur.
2. Ajouter des joueuses dans `player-stats.html` pour activer l'autocomplete.
3. Enregistrer les matchs et consulter les statistiques.

Les donnees sont stockees localement dans le navigateur (localStorage).
